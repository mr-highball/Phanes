# Catalog regional bounded review 01 evidence

This directory is the immutable archive of the 31 generated artifacts examined
for `reviews/catalog-regional-bounded-01.json`. The files are byte copies of the
historical paths registered below `build/`; their relative names are preserved
with the initial `build/` removed. Routine generated output continues to belong
under ignored `build/`. The directory-local attributes disable text conversion
for every evidence file so Git stores and checks out the reviewed bytes exactly;
the README and attributes file themselves remain canonical LF text.

Commit `c77b5797a87228bc1c7572befe6272da1971f054` is the current source checkpoint
when this archive was prepared. It is **not** the source checkpoint that
originally generated these historical artifacts. The retained provenance binds
the evidence it records, including Castle Engine commit
`050f07edde6652d6657b4fe0d299822b9f502afa`; this README does not broaden that
provenance.

- `docs/CATALOG_EXPANSION.md`
- `docs/CATALOG_PUBLICATION.md`

This archive therefore conveys no acceptance of the current implementation.
It makes the exact evidence reviewed in report 01 available in a clean checkout
so an independent critic can assess its continuing relevance. The critic report,
feature registry, grades and gate remain unchanged until that review occurs.

At archive creation, all 31 source and destination raw SHA-256 hashes matched,
and every destination also matched review 01 using the native checker's text
normalization. The evidence set contains 31 files totaling 11,073,018 bytes,
excluding archive metadata. The preparation manifest is retained in ignored output at
`build/catalog-regional-review-evidence-archive-manifest-01.json`.
